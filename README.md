# Biblioteca Digital UniFECAF

Projeto acadêmico da disciplina Design Web que transforma o protótipo fornecido no enunciado em uma interface responsiva para uma biblioteca digital universitária.

## Estrutura do projeto

- `index.html`: conteúdo e estrutura semântica da página.
- `css/style.css`: estilos, identidade visual e adaptações para diferentes larguras de tela.
- `assets/imagens/`: diretório reservado para imagens locais. As ilustrações desta versão são construídas com CSS.

## Implementação

A página reúne navegação, apresentação da biblioteca, livros em destaque, unidades e contato. Os links do menu direcionam para as seções correspondentes. O layout usa HTML e CSS, sem JavaScript, frameworks ou dependências externas.

A folha de estilos utiliza grades, tamanhos fluidos e media queries para reorganizar os conteúdos entre desktop, telas médias e smartphones. A paleta em azul e verde foi inspirada no material de referência do trabalho.

## Escopo do conteúdo

Os títulos de livros e as localidades exibidos na interface são exemplos demonstrativos. Eles não confirmam dados do acervo, disponibilidade, endereços ou serviços reais da UniFECAF. A página não oferece busca, login ou empréstimo.

## Acessibilidade

A interface declara o idioma `pt-BR`, utiliza regiões semânticas e hierarquia de títulos, inclui um link para pular ao conteúdo, foco visível para navegação por teclado, descrições para ilustrações informativas e suporte à preferência por movimento reduzido. A validação de contraste e os testes com teclado e leitor de tela devem ser feitos no ambiente de avaliação.
