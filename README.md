# Biblioteca Digital UniFECAF

Projeto acadêmico de Design Web: uma interface demonstrativa responsiva baseada na estrutura do protótipo fornecido no enunciado.

## Estrutura

- `index.html`: conteúdo semântico e seções da página.
- `css/style.css`: identidade visual, layout e regras responsivas.
- `assets/imagens/`: reservado para imagens locais; a interface atual constrói as ilustrações com CSS para manter o carregamento leve.

## Como visualizar

Abra `index.html` em um navegador moderno. O projeto não utiliza bibliotecas, frameworks, JavaScript ou dependências externas.

## Decisões e limites

O layout mantém a navegação, apresentação da biblioteca, livros em destaque, unidades e contato presentes no protótipo. Os títulos de livros e a lista de unidades aparecem como conteúdo demonstrativo e não representam confirmação de acervo, disponibilidade, endereços ou serviços reais. A página não implementa busca, login ou empréstimo, pois essas funcionalidades não fazem parte do escopo de HTML e CSS solicitado.

## Publicação gratuita

### GitHub Pages
1. Crie um repositório público e envie todos os arquivos desta pasta.
2. Em **Settings > Pages**, selecione a branch `main` e a pasta `/ (root)`.
3. Salve e aguarde a URL pública indicada pelo GitHub.

### Netlify
1. Entre na área de deploy manual do Netlify e arraste esta pasta ou conecte o repositório.
2. Não é necessário comando de build; publique a pasta raiz.
3. Confirme o endereço público disponibilizado.

## Acessibilidade

A página inclui idioma declarado, regiões semânticas, hierarquia de títulos, link para pular conteúdo, rótulos de navegação, foco visível, textos alternativos e adaptação a preferência por movimento reduzido. Para uma entrega institucional real, valide contraste com ferramenta automática e teste navegação por teclado e leitor de tela.
